## 📌 نبذة تعريفية (Executive Overview)

**منظومة التخطيط المالي واستدامة الدين العام السيادي** هي منصة محاكاة ونمذجة مالية واقتصادية كمية موجهة لصناع القرار، ومسؤولي مكاتب إدارة الدين العام (**Debt Management Offices - DMO**)، ووزارات المالية، والبنوك المركزية، والباحثين الماليين.

تجمع المنظومة بين أدوات التحليل المالي الكلي المعتمدة لدى **صندوق النقد الدولي (IMF)** و**البنك الدولي** وبين واجهة تفاعلية فورية تمكّن من:
1. تقييم استدامة المديونية العامة والمسار التوقعي حتى عام **2030م**.
2. اختبارات الجهد والتحمل المالي ضد الصدمات المعاكسة (**Stress-Testing & Sensitivity Analysis**).
3. إعداد أطر الميزانية متوسطة الأجل (**MTFF**) وفق المعايير الإحصائية الدولية لموازين الحكومات (**GFS 2014**).
4. إدارة الالتزامات والأصول السيادية ومراقبة جدار استحقاقات الديون ومخاطر إعادة التمويل (**ALM & Refinancing Risk**).
5. إصدار مذكرات وتقارير إحاطة تنفيذية جاهزة للطباعة والعرض على المجالس الاقتصادية العليا ومجلس الوزراء.

## 📐 الأسس الرياضية والنماذج الاقتصادية (Methodology & Mathematical Formulations)

### 1. معادلة ديناميكية الدين العام السيادي (IMF Debt Dynamics Equation)
تحسب المنظومة التغير في نسبة الدين العام إلى الناتج المحلي الإجمالي سنوياً وتراكمياً استناداً إلى نموذج صندوق النقد الدولي الرسمي:

$$\Delta d_t = \left[ \frac{r_t - g_t}{1 + g_t} \right] d_{t-1} - pb_t + sfa_t$$

* **$\Delta d_t$**: التغير السنوي في نسبة الدين إلى الناتج المحلي الإجمالي ($d_t - d_{t-1}$).
* **$r_t$**: معدل الفائدة الحقيقي الفعلي على محفظة الدين ($\text{Effective Nominal Rate} - \pi_t$).
* **$g_t$**: معدل نمو الناتج المحلي الإجمالي الحقيقي.
* **$pb_t$**: الرصيد المالي الأولي كنسبة من الناتج (الإيرادات العامة باستثناء الفوائد - النفقات باستثناء الفوائد).
* **$sfa_t$**: تعديلات رصيد التدفق النقدي والعملات الأجنبية (Stock-Flow Adjustments & FX Valuation Effects).
* **أثر كرة الثلج (Snowball Effect)**: يُعرف بالمقدار $\left[ \frac{r_t - g_t}{1 + g_t} \right] d_{t-1}$، حيث تتسع المديونية ذاتياً عندما تتجاوز أسعار الفائدة الحقيقية معدل نمو الاقتصاد.

### 2. الرصيد الأولي المثبت للدين (Debt-Stabilizing Primary Balance)
لحساب الفائض أو العجز الأولي المطلوب حسابياً للحفاظ على نسبة الدين عند مستواها الحالي دون زيادة:

$$pb^* = \left[ \frac{r - g}{1 + g} \right] \cdot d$$

تقوم المنظومة آلياً بحساب فجوة الاستدامة المالية (**Fiscal Sustainability Gap**) لمقارنة الرصيد الأولي المخطط بالرصيد المطلوب للتثبيت.

### 3. الرصيد المالي الهيكلي والدافع المالي (Structural Balance & Fiscal Impulse)
لعزل أثر الدورة الاقتصادية والتقلبات الاستثنائية للأسواق:

$$\text{CAPB}_t = \text{PB}_t - \epsilon \cdot \text{OutputGap}_t$$
$$\text{Fiscal Impulse}_t = - (\text{CAPB}_t - \text{CAPB}_{t-1})$$

* **$\text{OutputGap}$**: فجوة الناتج (النمو الفعلي مقارنة بالنمو الكامن طويل الأجل).
* **$\epsilon$**: شبه المرونة الهيكلية للميزانية العامة تجاه الدورة الاقتصادية.
* **الموقف المالي**: يحدد ما إذا كانت السياسة المالية العامة للدولة ذات طابع تحفيزي توسعي (**Expansionary**) أم ضبط مالي انكماشي (**Consolidation**).

### 4. محاكاة مروحة الثقة العشوائية (Stochastic Fan Chart Bands)
توليد نطاقات الاحتمالية الإحصائية (P10، P25، P50، P75، P90) باستخدام محاكاة صدمات عشوائية مجمعة لمعدلات النمو، الفائدة، والإيرادات عبر 1000 تكرار مع حساب مصفوفات التغاير التاريخية.

### 5. إدارة الالتزامات والأصول (Asset-Liability Management Metrics)
* **متوسط أجل الاستحقاق المرجح (Weighted Average Maturity - WAM)**:
  $$\text{WAM} = \frac{\sum (T_i \times \text{Principal}_i)}{\sum \text{Principal}_i}$$
* **مدة ماكولي والمدة المعدلة (Modified Duration)** لقياس حساسية القيمة السوقية لمحفظة السندات لتغير 100 نقطة أساس في العوائد.

## 🖥️ التبويبات والوحدات الرئيسية للمنظومة (Core Functional Modules)

### 1. إطار التخطيط المالي متوسط الأجل (MTFF)
* عرض متكامل لجداول المالية العامة وفق تصنيف **IMF GFS 2014**:
  * الإيرادات: نفطية/مباشرة، ضرائب على الدخل، ضرائب غير مباشرة (القيمة المضافة والجمارك)، وإيرادات غير ضريبية.
  * النفقات: تعويضات العاملين (الأجور)، السلع والخدمات، الإعانات والتحويلات الاجتماعية، الفوائد، والإنفاق الرأسمالي التنموي.
* تقييم مدى الالتزام بـ **القواعد والضوابط المالية (Fiscal Rules Compliance Audit)**:
  * قاعدة سقف الدين إلى الناتج (%GDP).
  * قاعدة سقف الاحتياجات التمويلية الإجمالية (GFN).
  * قاعدة ضبط عجز الميزانية.
* مخطط تطور بنود الميزانية ومخطط الرصيد الهيكلي والدافع المالي.

### 2. تحليل استدامة الدين العام (DSA Hub)
* **مخطط تفكيك ديناميكية الدين العام (Waterfall Decomposition)**: عرض تفاعلي لمساهمة كل محرك (النمو، الفائدة، الرصيد الأولي، الصرف) سنوياً وتراكمياً حتى 2030م.
* **مصفوفة الإنذار المبكر ومخاطر الديون السيادية (Sovereign Vulnerability Heatmap)**: رصد 7 مؤشرات رئيسية للهشاشة المالية وفق منهجية **MAC-DSA** بنظام الإشارات الضوئية مع مؤشر مركب من 0 إلى 100.
* **منحنى العائد السيادي (Sovereign Yield Curve Benchmark)**: عرض هيكل آجال أسعار الفائدة من 3 أشهر حتى 30 سنة، ومقارنة المنحنى مع كبرى الاقتصادات العالمية، وحساب فارق الميل (Slope Spread 10Y-2Y) لرصد إشارات الركود.
* **مخطط الفارق بين الفائدة والنمو $(r - g)$**: رصد مباشر لظاهرة كرة الثلج.
* **مقارنة الأقران السياديين (Peer Benchmarking)**: مقارنة فورية بين الدول الست في الديون، العجز، والعوائد.

### 3. نمذجة السيناريوهات واختبارات الجهد (Scenario Modeling & Stress Testing)
* لوحة تحكم ديناميكية تتيح تطبيق صدمات مباشرة:
  * صدمة أسعار النفط (USD/bbl).
  * صدمة نمو الناتج الحقيقي (Real GDP Growth).
  * صدمة تكلفة الاقتراض وهوامش المخاطر (+/- bps).
  * تعديل النفقات التشغيلية والرأسمالية.
* **مخطط الإعصار لحساسية الديون (Stress-Testing Tornado Diagram)**: فرز الصدمات الأكثر تأثيراً على دين عام 2030م تنازلياً.
* **مخطط مروحة التنبؤ الاحتمالية (Fan Chart)**: مقارنة مسار خط الأساس بالمسار المحاكى ونطاقات الثقة الإحصائية.
* **أداة مصفوفة الحساسية ثنائية الأبعاد (Two-Way Sensitivity Matrix)**: فحص تفاعل متغيرين معاً (مثل أسعار النفط مقابل تكلفة الاقتراض).

### 4. هيكل ومحفظة الدين العام (Debt Structure & ALM)
* **جدار استحقاقات الديون السيادية (Sovereign Maturity Wall)**:
  * جدول الاستحقاقات حتى 2035م+ مع تحديد سنة ذروة الاستحقاق (**Refinancing Peak**).
  * إمكانية الفرز حسب نوع العملة (محلي مقابل أجنبي) وحسب نوع الفائدة (ثابت مقابل متغير).
  * مؤشرات WAM وModified Duration وحجم محفظة الصكوك والسندات.
* سجل تفصيلي لشرائح وأدوات الدين الصادرة (السندات الخضراء، الصكوك السيادية، السندات الدولية، القروض المجمعة).
* جدول سداد الأقساط والفوائد السنوية.

### 5. الأدوات التنفيذية المساعدة
* **مفتش ومطابق البيانات السيادية (Verified Data Inspector)**: مراجعة كافة المصادر الأولية والمراجع الإحصائية الرسمية لكل دولة.
* **مولد مذكرة الإحاطة التنفيذية (Executive Briefing Report Modal)**: تصدير تقرير تنفيذي رسمي جاهز للطباعة موجه إلى مجالس الوزراء واللجان الاقتصادية العليا يوجز المخاطر، التوقعات، والتوصيات المالية الاستراتيجية.
* **شريط المؤشرات الاقتصادية اللحظي (Macro Ticker)**: رصد دائم في أعلى الصفحة لأسعار النفط، معدلات الفائدة، عوائد السندات، وأسعار الصرف.

## 🚀 التشغيل والتطوير المحلي (Getting Started)

### المتطلبات الأساسية
* بيئة تشغيل **Node.js** (إصدار 18 أو أحدث)
* مدير الحزم **npm** أو **bun**

### خطوات التثبيت والتشغيل
```bash
# 1. استنساخ المستودع
git clone <repository-url>
cd sovereign-debt-sustainability

# 2. تثبيت الحزم والاعتماديات
npm install

# 3. تشغيل الخادم المحلي للتطوير
npm run dev
```

سيتم تشغيل المنصة تلقائياً على الرابط: `http://localhost:3000`

### أوامر الفحص والتحقق
```bash
# فحص الأنواع وعدم وجود أخطاء برمجية
npm run lint

# بناء نسخة الإنتاج النهائية
npm run build
```

## 🔒 معايير الجودة والموثوقية (Standards & Compliance)
